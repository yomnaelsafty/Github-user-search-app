# GitHub User Search App

A simple, interactive web application to search for GitHub users and view their profiles.  
Built using **HTML, CSS, and JavaScript** with a focus on clean design and responsive layout.

---

## 🚀 Features

- 🔍 Search for any GitHub user by username  
- 📄 View user profile information including avatar, bio, and repositories  
- ✅ Responsive design for desktop and mobile  
- 🎨 Clean UI with modern styling  
- 💻 Dynamic interactivity powered by JavaScript  

---

## ▶️ How to Use

1. Open `index.html` in your browser  
2. Enter a GitHub username in the search input  
3. Press **Enter** or click the search button  
4. View the user's profile and repository information  

---

## 💻 JavaScript Usage

- Handles search input and button click events  
- Fetches user data from GitHub API  
- Dynamically updates the page with user profile and repositories  
- Provides error handling for invalid usernames
